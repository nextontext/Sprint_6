## Создание отчета в Allure
**Предварительное условие**, на компьютере установлен Allure

Можно проверить командой:
```
allure --version
```
Будет показана версия allure


1. Запустить тесты с флагом `--alluredir=allure_results`
```bash
python -m pytest --alluredir=allure_results
```
2. В проекте будет создана папка с результами тестов
3. Запустить Allure
```bash
allure serve allure_results
```
